내 기관 점검표·보고서

기록으로 확인한 항목을 안내합니다. 공식 평가의 합격·불합격 판정은 하지 않습니다.

본인 기관의 업무만 처리하세요

  1. 개인 연습은 기관을 선택합니다. 합동훈련은 기관별 초대 링크로 입장합니다.
  2. 우리 기관 보고를 읽고 필요한 정보를 공동 공유합니다.
  3. 받은 요청은 수락 또는 조정 회신합니다. 필요한 지원은 상대 기관에 요청합니다.
  4. 수락하면 자원이 배정되고 시간이 흐르면서 작업이 진행됩니다. 다른 기관으로 전환하지 않습니다.
  5. 결과 보고를 확인·공유하고 다음 조치를 판단합니다.

현재 13개 참여 슬롯은 예시 기관 구성입니다. 실제 기관 명칭과 권한은 훈련계획에 맞춰 확인해야 합니다. 지도 표식과 위험 변화는 훈련 가정입니다.

기관별 초대 링크와 접속코드는 비밀번호처럼 관리하세요. 공동훈련방은 24시간 유효합니다. 생성형 AI 연결이 없으면 규칙 기반으로 시나리오를 자동 구성하고 표시합니다.
