PRACTICE GUIDE

세부 가이드

훈련 중 언제든 참고할 수 있습니다.

훈련 진행 순서
  1. 기관별 보고를 읽고 필요한 정보를 공유합니다.
  2. 임무와 판단 근거를 작성합니다.
  3. 담당 기관 역할에서 수락 또는 대안을 회신합니다.
  4. 훈련통제로 전환해 시간을 진행합니다.
  5. 결과 보고를 공유하고 다음 판단을 기록합니다.
요청 문장 예시

고립 신고 6명을 우선 확인하고 구조·이송을 요청합니다. 요양시설 대피 수요와 자원 중복을 확인해 가능한 출동 시점을 회신해 주세요.

모델의 가정

이송팀은 1대, 한 번에 최대 6명입니다. 12분에 도로가 단절되며 우회는 5분 추가됩니다. 통제 전 5분마다 고립 2명이 추가됩니다. 현업 검증 전의 교육용 가정입니다.

DREX · NEW EXERCISE

어떤 방식으로 훈련할까요?

가상 지역 호우 · 5개 기관 역할 · 훈련시간 최대 60분

모드는 한 실행 동안 유지됩니다. 새 훈련을 시작하면 이전 기록을 보관합니다.

사용법·역할 안내

한 기기에서 역할을 바꾸며 기관 간 판단 과정을 시험하는 버전입니다.

  1. 현재 역할을 선택하고 보고를 읽습니다.
  2. 보고의 ‘공동 공유’를 누르면 다른 역할에서도 확인됩니다.
  3. 임무를 요청한 뒤 담당 기관으로 역할을 바꿔 수락합니다.
  4. 훈련통제 역할에서 시간을 진행하면 이동·작업이 실행됩니다.
  5. 종료 후 기록·사후강평에서 결과와 당시 보고를 확인합니다.

실제훈련 중에는 세부 대응 가이드가 나타나지 않습니다. 종료 후 강평 자료를 확인할 수 있습니다.
