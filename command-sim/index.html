사용법·역할 안내

한 기기에서 역할을 바꾸며 기관 간 판단 과정을 시험합니다. 지도는 실제 지형이며 사건·기관의 위치와 위험반경은 훈련 가정입니다. 지역 검색은 지도 시점만 이동하며 사건 배치는 바꾸지 않습니다.

  1. 현재 역할을 선택하고 보고를 읽습니다.
  2. 보고의 ‘공동 공유’를 누르면 다른 역할에서도 확인됩니다.
  3. 임무를 요청한 뒤 담당 기관으로 역할을 바꿔 수락합니다.
  4. 훈련통제 역할에서 시간을 진행하면 이동·작업이 실행됩니다.
  5. 종료 후 기록·사후강평에서 결과와 당시 보고를 확인합니다.

지역 검색 시 입력 지역명이 OpenStreetMap Nominatim에 전달됩니다. 지도 출처는 지도 하단에 표시합니다. 수행 임무 연결선은 실제 도로 경로가 아닙니다.

실제훈련 중에는 세부 대응 가이드가 나타나지 않습니다. 종료 후 강평 자료를 확인할 수 있습니다.
