# DREX 중앙 통합지휘 상황판 연결

기준: main bf4d3efbf79c5d5e076c9afffa2150d3c0174e2c.
별도 DREX 3.x 실험 기능은 포함하지 않습니다.

## 적용 파일
- index.html: 기존 중앙 소형 상황도를 command-map.html로 교체. 기관·훈련 단계 전달, 지도 확대, 훈련별 배치 보관.
- command-map.html: 지도, 기관 배치, 현장 메모, 녹화 영상 연결. 기관 상태는 본체에서 읽기 전용으로 갱신.
- vercel.json: 상황판 정적 경로와 동일 출처 프레임 허용. 그 외 페이지의 프레임 차단 유지. 기존 혼합 headers/routes를 routes로 정리.

## 사용
기존 통제관 훈련 시작 후 중앙 상황판에서 기관을 선택하고 지도에 위치를 지정합니다.
기관의 실제 위치를 자동 추적하거나 임의 배치하지 않습니다.
기관 상태 변경은 기존 DREX 기관 제어에서 수행하고, 지도 측 입력은 현장 메모입니다.
일반지도는 지역 개요(원본 확대 수준 12), 항공영상은 세부 현장 확인용입니다.
CCTV는 실시간 미연결이며 권한 있는 로컬 녹화 파일만 재생합니다.
지도 배치·메모는 기존 drex_ttx 저장 데이터에 포함됩니다. 브라우저 저장 삭제 시 사라지므로 상황 JSON도 내려받으세요.

## 검증
- DREX 13개 기관 상태 전달 및 상태 갱신
- 기관 선택→수동 지도 배치→본체 저장
- 메모 저장 및 iframe 재로드 복원
- 새 훈련 ID에서 이전 배치 초기화
- 다른 메시지 발신자의 snapshot 거부
- 지도 확대 / 문법·diff 검사
지도·검색 외부 연결 자체는 이전 시안에서 별도 실수신 확인. 이번 연결 회귀 시험에서는 외부 요청 차단.
