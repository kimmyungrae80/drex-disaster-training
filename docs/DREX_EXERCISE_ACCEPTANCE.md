# 목표 기반 통합훈련실 검증 기록

작성: 2026-11-02 UTC. 이번 변경은 별도 브랜치와 `/exercise/` 경로에 한정하며 기존 `main`을 교체하지 않는다.

## 자동 검증

`node --check` 구문 검사 통과. 새 통합훈련 테스트 19개와 기존 공동훈련 회귀 테스트 8개, 합계 **27개 통과**.

- 서버에서 실제 모의 상태·기관 전용 정보·공유 정보를 분리.
- 기관별 초대 변조, 타 기관 조치, 운영자의 대리 조치 거부.
- 한 기관의 다중 참가, 기관 내부훈련, 기관명·임무 변경.
- 요청 → 수락 → 착수 → 모의 결과 → 요청기관 확인.
- 가용 자원 중복 사용 차단, 선행조건 미충족 시 대기.
- CAS 기반 동시 수정, 동일 요청 ID 재전송, 재훈련 중복 개설 방지.
- 판단 당시 정보 사본 보존.
- 추가 메시지와 모의 상태 변경 분리, 자유 대응의 운영자 판정.
- 일시정지·종료, 7일 만료, 다른 Origin 요청 거부.
- 미확인을 자동 실패로 처리하지 않음. 실제 기관과 모의기관 실적 분리.
- 강평 검토와 재검증에 근거 요구. 재검증에는 담당기관의 이번 행동 기록을 요구.
- AI에는 공개 브리핑 입력만 전달. AI 설정 누락·실패를 기본 시나리오로 명시.

이는 메모리 저장소를 사용하는 서비스/엔진 테스트다. 실제 Vercel·Supabase 연동, 대규모 동시접속, 실제 AI 출력 품질까지 검증한 결과가 아니다.

## 화면 검증

브라우저에서 서버 연결, 목표·방식 설정, 지역·기관 편집 화면을 확인했다. OSM 배경지도가 403 정책 안내 이미지를 표시하는 문제를 발견했다. Referrer 정책 확인 후에도 동일하여 새 화면을 Esri 항공영상/참고 일반지도 구성으로 변경했다. 지도 레이어 선택을 항상 표시하고 화면 갱신 시 선택을 유지하도록 했다.

이후 로컬 미리보기 재접속 단계가 브라우저 URL 정책에서 차단됐다. 해당 브라우저 경로를 우회하지 않았다. 따라서 **교체 지도의 최종 렌더링, 여러 실제 탭의 전 과정, 모바일, 보고서 다운로드의 화면 검증은 미완료**다. 서비스 호출 기반 기능 테스트와 구분한다.

## 현장 시범 전 확인할 항목

1. 프리뷰에서 Supabase 연결 상태 및 서로 다른 기기의 입장·재접속 확인.
2. 운영자 1명과 기관 담당자 2명 이상이 요청부터 결과 확인까지 수행. 미참여 기관은 모의임을 확인.
3. 기관 담당자가 다른 기관의 비공개 정보·운영자 실제 상태를 볼 수 없는지 확인.
4. 지도·항공영상, 중심 좌표 지정, 화면 크기별 가독성 확인.
5. 기관의 실제 매뉴얼·용어·자원·시간 가정 검토. 교육용 조건을 현장 전술 기준으로 오해하지 않는지 확인.
6. 강평보고서 내용과 열람 범위 확인, 개선과제 등록 후 변형 재훈련 및 근거 검토.
7. 공식 평가 적용은 해당 평가표 원문과 관찰 기준을 별도로 검증한 후 결정.
