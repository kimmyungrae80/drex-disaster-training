# DREX 통합훈련실 — 목표 기반 훈련 시범 버전

## 기존 DREX와의 관계

기존 첫 화면과 운영 중인 훈련은 유지한다. 새 화면은 `/exercise/`, 새 API는 `/api/exercise`다. 기존 `feat/drex-command-sim`의 저장소 연결을 재사용하되, 새 훈련 데이터는 `DREX-EXERCISE-2` 유형으로 구분한다. 원래 프로그램을 대체하거나 `main`에 자동 병합하지 않는다.

이번 구현은 **집중호우로 가상 시설이 고립된 상황** 한 가지를 끝까지 시험하기 위한 것이다. 모든 재난의 검증된 시뮬레이션, 실제 재난 지휘 시스템, 공식 평가 프로그램이 아니다. 선택한 지역에 실제 사고나 위험이 있다고 주장하지 않는다.

## 왜 이 구조인가

훈련에서 확인할 것은 화면의 사건 수보다, 각 기관이 제한된 정보를 확인하고 다른 기관과 협력해 필요한 일을 마쳤는가이다. 따라서 다음을 분리한다.

1. **훈련상 실제 상태**: 서버가 관리하며 운영자만 볼 수 있다.
2. **기관별 정보**: 서로 다른 신고·보고를 받는다. 참가자는 입장한 기관으로 고정된다.
3. **공동상황도**: 기관이 공유한 보고를 지도에 표시한다. 아직 공유하지 않은 사실을 자동 공개하지 않는다.

재난 자체의 시간·자원·선행조건은 규칙으로 처리한다. AI는 검토할 초기 브리핑을 보조하고, 임의로 현장 결과나 평가점수를 확정하지 않는다. 목록 밖의 대응은 운영자가 근거를 남겨 판정한다.

## 처음 사용하는 순서

### 1. 운영자가 훈련을 준비한다

- 목표 1~3개를 선택한다: 정보 확인·공유 / 기관 간 협조 / 판단과 결과 확인.
- 관찰할 행동과 근거 문서를 기관에 맞게 수정한다. 기본 문구는 교육용이며 공식 평가표가 아니다.
- 연습훈련 또는 실전형 모의훈련을 선택한다. 연습에는 단계별 안내가 있고, 실전형에는 정답 순서가 없다. 목표·참고 근거는 두 방식 모두 열람할 수 있다.
- 개인 연습 / 한 기관 내부훈련 / 여러 기관 합동훈련을 별도로 선택한다.
- 지역을 `○○시 ○○동 일대`로 기재하고 필요하면 주소를 추가한다. **중심 위치는 지도 클릭 또는 표식 이동으로 설정**한다. 주소의 자동 좌표 검색은 아직 없다.
- 2~20개 기관의 이름과 모의 임무를 지정한다. 기본은 상황총괄·소방·경찰·시설관리·대피구호 5개다. 13개 협업기능을 13개 실제 기관과 동일하게 취급하지 않는다.
- 초기 브리핑과 교육용 가정을 확인하고 훈련방을 개설한다.

### 2. 기관별 담당자가 입장한다

- 운영자가 기관별 초대 링크를 복사해 해당 담당자에게 전달한다.
- 한 기관에 최대 10명이 각각 입장할 수 있다. 다른 기관으로 역할을 전환할 수 없다.
- 훈련 시작 전에 기관 구성을 확정한다. 시작 후에는 기존 브라우저의 **내 훈련 → 다시 입장**으로 복원한다.
- 미참여 기관 모의를 켠 경우 규칙 기반 기관이 요청에 응답한다. 실제 사람의 참여·성과와 구분해서 표시한다.
- 초대 링크는 입장 권한이다. 기관 담당자에게만 전달한다. 이는 기관 SSO나 직원 신원 검증을 대신하지 않는다.

### 3. 본인 기관의 임무를 수행한다

1. **공동상황도**에서 내 기관의 보고, 정보 출처, 확인 상태를 확인한다.
2. 확인한 정보를 공유하고, 필요하면 새 상황보고를 작성한다.
3. **협업·조치**에서 수신 기관과 필요한 임무를 선택해 요청한다. 자체 임무는 자기 기관에 등록한다.
4. 수신 기관은 수락·회신 또는 대안·불가를 회신한다. 수락 뒤 **조치 착수**를 눌러야 진행된다.
5. 모의 결과가 도착하면 요청 기관이 **결과 확인 기록**을 남긴다. 결과 회신만으로 협업 완료가 되지 않는다.
6. **판단·기록**에 판단 이유와 당시 보았던 보고를 선택한다. 해당 시점의 보고 사본을 보존한다.

기본 샘플은 기관별 가용 팀을 1개로 가정한다. 현장 지원은 진입로·전기 안전·대피시설 준비 조건을 충족해야 진행된다. 이 조건과 처리 시간은 교육용 모델의 가정이며 실제 구조 지침이 아니다.

### 4. 강평하고 다시 확인한다

- 종료하면 관찰 기록을 목표별로 묶는다. 기록이 없다는 이유로 실패를 자동 판정하지 않는다.
- 운영자는 근거 기록을 선택하여 목표 충족 / 보완 필요 / 판단 유보를 검토한다.
- 개선과제에 담당기관·기한·다음 훈련에서 확인할 행동을 입력한다.
- **조건을 바꿔 재훈련 개설**을 누르면 개선과제를 이어받은 새 방을 만든다. 이전 훈련 기록은 그대로 남는다.
- 재훈련에서는 T+8분에 진입로 조건이 달라지는 변형을 사용한다. 운영자는 종료 후 담당기관의 이번 훈련 행동 기록을 근거로 재검증 완료 또는 추가 보완을 기록한다.
- 보고서는 HTML로 저장할 수 있고, 브라우저 인쇄에서 PDF로 저장할 수 있다. JSON 기록도 내려받을 수 있다. 참가자 보고서는 해당 기관의 열람 범위로 제한한다.

| 구분 | 이번 구현 | 후속 개발·현장 검증 |
|---|---|---|
| 시나리오 | 집중호우 1종, 목표·기관·지역 조정, 변형 재훈련 | 재난별 모델 라이브러리, 지역 위험자료 검증 |
| AI | 기존 Groq 설정이 있을 때 초기 브리핑 초안 생성 | 원문 매뉴얼 검색, 근거 인용형 AI 강평·보고서 서술 |
| 협업 | 기관별 초대·고정 권한·동시 입력·다중 참가 | 기관 계정/SSO, 관리자 승인·회수, 부하·침투 점검 |
| 모의 | 시간·선행조건·가용 팀·요청 결과·운영자 판정 | 이동시간·자원 종류·대체경로·복합재난 검증 |
| 지도 | 지도 클릭 중심 설정, 항공영상/일반지도, 공유 보고 위치 | 기관용 지도 계약·키 설정, 주소검색, 실제 시설 GIS |
| 평가 | 행동 기록·판단 근거·수동 검토·HTML 보고서 초안 | 해당 연도의 공식 점검표 원문 검증·매핑, 평가자 간 일치도 |
| 환류 | 담당·기한·완료 기록·변형 재훈련·근거 기반 재검증 | 장기 과제 관리, 알림, 기관별 훈련 이력 |
| 현장감 | 실제 지도 배경과 가상 사건 표시 | 승인된 CCTV·드론·3D 연계 |

실제 참여기관끼리 요청부터 결과 확인까지 마친 건과 모의기관 포함 완료 건을 분리한다. 회신시간은 모의시간 기준이며 실제 현장 출동시간이 아니다. 아직 표본이 충분하지 않으므로 P50/P95, 비용 절감률, 국가 평가점수 상승을 산출하거나 보장하지 않는다.

## 지도 제공 방식

- 기본은 Esri World Imagery, 일반지도는 Esri World Street Map 참고 레이어다. 출처를 지도에 표시한다.
- OSM 공용 타일은 검증 브라우저에서 정책 안내가 포함된 403 이미지를 반환해 새 화면의 기본 공급자에서 제외했다. 실패 시 무한 재시도하거나 프록시로 우회하지 않는다.
- Esri의 레거시 일반지도는 최신성이 제한된다. 공식 안내상 2021년 이후 갱신되지 않았으며 World Street Map은 2029년 12월 종료 예정이다. 본 샘플의 배경 확인용이며 최신 도로·통제 정보가 아니다.
- 기관 서비스 적용 전 최신 지도 공급자와 이용 조건을 확정하고 계약/API 키 기반 레이어로 교체해야 한다. 인터넷 차단 환경에서는 좌표 입력과 훈련 기록은 사용할 수 있지만 배경지도는 제공되지 않는다.
- 타일 오류 시 레이어 변경 안내를 표시한다. 현재 환경에서 교체 후 실제 항공·일반지도 렌더링의 최종 검증은 남아 있다.

## 실행·배포

로컬 실행은 Node.js 24 권장(최소 22.13)이다. 추가 npm 의존성은 없다.

```sh
npm run dev
# http://localhost:3000/exercise/
npm run check:exercise
node --test tests/exercise.test.mjs tests/command-room*.test.mjs
```

로컬에서는 `/tmp/drex-objective-exercises.sqlite`에 저장한다. 경로는 `DREX_EXERCISE_DB`로 변경한다. 로컬 서버의 기본 바인딩은 `0.0.0.0`이며 개인 PC에서만 사용할 때는 `DREX_BIND=127.0.0.1`로 제한한다. 로컬 개발 서버에는 AI 공급자를 연결하지 않았다.

Vercel에서는 기존 `server/command-room-store.mjs`의 Supabase 저장소를 사용한다.

- `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`: **동일한 Supabase 프로젝트**의 서버 환경변수.
- `practical_sessions` 테이블: 기존 [배포 안내](DEPLOY-PRACTICAL.md)의 구조 사용.
- `GROQ_API_KEY`, 선택적 `GROQ_MODEL`: AI 초기 브리핑용. 기존 DREX 공급자 설정을 재사용한다. 설정이 없거나 실패하면 기본 시나리오라고 명확히 표시한다.
- 서버 키를 브라우저에 전달하지 않는다. 서버 엔진은 `/exercise/` 정적 파일 허용 목록에 포함하지 않는다.
- 프리뷰 배포에도 환경변수가 적용돼야 공동훈련이 동작한다. 환경변수 누락을 화면 데모 성공으로 숨기지 않는다.

방의 접근 유효기간은 7일이다. **만료는 접근 제한이며 DB의 물리 삭제가 아니다.** 기관 운영 전 보관정책·정리 작업·계정 관리·요청량 제한을 별도로 설정해야 한다. 현재 공개 개설 방식은 소규모 시험용이며 인증된 기관 서비스의 보안 요건을 충족했다고 주장하지 않는다.

## 설계 참고자료

아래는 설계 접근법 참고자료다. 새 샘플의 자체 점검표를 공식 평가지표로 인증하는 근거가 아니다.

- [FEMA HSEEP](https://training.fema.gov/programs/nsec/hseep/): 목표·역량 기반 훈련, 평가와 개선 계획.
- [FEMA Exercise Evaluation Guides](https://preptoolkit.fema.gov/web/hseep-resources/eegs): 관찰 기준과 근거 구조.
- [JESIP Supporting Decision Making](https://www.jesip.org.uk/joint-doctrine/supporting-decision-making/): 기관 간 정보·판단 공유.
- [미 육군 Mission Command Training Program](https://usacac.army.mil/Organizations/Combined-Arms-Command-Training-CAC-T/Mission-Command-Training-Program-MCTP): 지휘소 의사결정훈련의 참고 개념.
- [행정안전부 국가재난대비훈련](https://www.mois.go.kr/frt/sub/a06/b11/disasterTraining/screen.do): 국내 훈련 체계의 참고 범위.
- [Esri 레거시 지도 종료 안내](https://www.esri.com/arcgis-blog/products/arcgis-living-atlas/announcements/sunsetting-legacy-basemaps), [OSM 타일 이용정책](https://operations.osmfoundation.org/policies/tiles/).
