🏛️ TTX 상황판단회의 시뮬레이션

훈련 조건을 입력하면 TTX AI가 실전적인 TTX(테이블탑 시뮬레이션) 시나리오를 자동 생성합니다.

🎯 이 훈련은 무엇인가요?
TTX(테이블탑 시뮬레이션, Tabletop Exercise)는 실제 재난 발생을 가정하고 의사결정 절차를 토론·연습하는 상황판단회의입니다.
TTX AI가 실전 시나리오를 생성하고, 강도별 3~6라운드의 의사결정을 거쳐 대응 역량을 평가받습니다. 대응 성과에 따라 라운드가 줄거나(조기 안정화) 늘어날 수(위기 라운드) 있습니다.
⏱️ 소요 시간
· 시나리오 생성: 약 30초
· 라운드 의사결정: 라운드당 3~8분 (초급 3 / 중급 4~5 / 고급 6라운드)
· 최종 보고서: 약 1분
총 20~50분 소요
📋 훈련 진행 순서
1단계
훈련 조건 입력 — 기관명, 재난유형, 지역(+특성 태그), 훈련강도, 참여인원을 입력하고 시나리오를 생성합니다. 사전/사후 비교 훈련을 하려면 시뮬레이션 시드에 같은 숫자를 입력하세요.
2단계
라운드 상황판단회의 — 돌발상황마다 A·B·C 중 대응안을 선택합니다. 실시간 30초마다 재난시간 10분이 흘러 피해가 자동 증가하므로, 기관 카드를 클릭해 현장투입해야 피해 곡선이 꺾입니다. 60초 내 결정 시 신속성 만점.
3단계
AI 결과 분석 — 라운드 점수(규칙 60% + AI 40%)와 협업기관 운영 결과를 종합한 훈련 분석·RTO 산출·AI 보고서를 받습니다.

⚠️ 주의 사항
· 시나리오 생성 시 인터넷 연결이 필요합니다 (AI API 호출)
· 브라우저 뒤로가기 사용 시 진행 상황이 초기화될 수 있습니다
· 훈련 결과는 자동 저장되며 마지막 세션이 복원됩니다
· 훈련 강도 고급은 피해 규모가 1.6배 증폭되고 라운드가 6회로 늘어납니다
· 화면을 켜둔 채 방치하면 피해가 계속 진행됩니다 — 고민은 짧게, 기관 투입은 빠르게
훈련 조건 입력
해당하는 특성을 선택하면 시나리오 전개에 반영됩니다 (복수 선택 가능)
훈련에 참여하는 전체 인원 수 (단위: 명)
같은 시드 + 같은 조건 = 동일한 피해 규모·돌발 판정 재현 (사전/사후 비교 훈련용)
